## Course Description

Smart Prosthetics and Robotic Systems (formally, Biomechanical Measurements) is a senior-level elective in biomedical engineering that blends artificial intelligence, robotics, and human-centered device design. Students will gain hands-on experience in programming, mechanical design, rapid prototyping, electronics, kinematics, machine vision, and natural language interfaces.

Working in teams, students will design, fabricate, and program a multi-axis robotic arm inspired by prosthetic applications. The robotic arm will be controlled through Python on an Arduino, equipped with cameras for machine vision, and integrated with an AI chatbot capable of interpreting natural language commands such as: *"Place the green boxes in the yellow bin."*

The semester culminates in a final competition, where teams demonstrate creativity, versatility, and performance in robotic arm design and task execution.

---

## Course Format

Classes meet once weekly for three hours. Each session begins with a 20-minute instructor-led discussion introducing new concepts and practical methods for implementation. The remaining 160 minutes are dedicated to supervised build time, where students apply concepts directly to their robotic arm projects.

Several sessions will be reserved for full-class free build time, allowing extended prototyping, integration, and testing. This structure emphasizes experiential learning, iterative design, and collaborative problem-solving.

## Class Schedule

### Phase 1 — Foundations (Weeks 1–2)

1. Course goals
2. Introduction to Arduino
3. Motors and drives: drivers, PWM, stepper, and servo motors
4. Sensors: limit switches, encoders, potentiometers
5. CAD modeling, 3D printing, and fabrication

### Phase 2 — Programming Practices (Weeks 3–6)

6. Python programming
7. Version control (Git and GitHub)
8. AI-assisted programming ("vibe coding")

### Phase 3 — Control & Perception (Weeks 7–8)

9. Kinematics: forward kinematics, degrees of freedom, workspace design, inverse kinematics and trajectory planning
10. Machine vision: OpenCV basics (filters, contours, colors) and object detection pipelines (Roboflow)

### Phase 4 — AI & Chatbot Interfaces (Weeks 9–11)

11. Generative AI chatbots: overview and applications in assistive devices
12. API communication: authentication, tokens, Python wrappers
13. Prompt engineering: translating natural language into robot commands
14. Structured outputs: JSON commands and robot task mapping
15. Full system integration: prompt → API → robot action

### Phase 5 — Competition (Weeks 12–14)

16. Free build days (debugging & refinement)
17. Final competition and showcase

### Component Details

- **Final Competition Performance** — Effectiveness, accuracy, and speed of robotic arm execution.
- **Creativity and Design Innovation** — Novelty of design, problem-solving approach, and adaptability.
- **System Versatility** — Ability of the arm to handle varied objects and tasks.
- **Progress Milestones & Documentation** — Demonstrated iterative progress, code documentation, and project logs.
- **Participation and Teamwork** — Engagement during class, collaboration, and peer contribution.
- **Homework** — Course modules for programming and AI each week through DataCamp.
