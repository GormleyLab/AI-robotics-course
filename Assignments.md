## Assignment Categories

### Phase 1 — Foundations (Weeks 1–2)
Hardware fundamentals including motor control and CAD modeling for robotic arm design.

### Phase 2 — Programming Practices (Weeks 3–7)
Python programming fundamentals, version control with Git/GitHub, and AI-assisted development workflows.

### Phase 3 — Control & Perception (Week 8)
Computer vision basics using OpenCV and Roboflow for object detection pipelines.

### Phase 4 — AI & Chatbot Interfaces (Weeks 9–11)
OpenAI API integration, prompt engineering, and building natural language interfaces for robot control.

### Phase 5 — Competition (Weeks 12–14)
Final integration, testing, and competition preparation.
